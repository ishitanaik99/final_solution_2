Captain · Agent 1 of 4

Shift assistant

Watches the order forecast, switches the store between Quiet, Normal, Busy and Very busy, books on-demand pickers by the hour when the forecast is high, asks you before calling extra staff, and briefs you in Hindi.

Technical details
Ledger · Agent 2 of 4

Stock checker

Every time a picker finds a shelf empty, Ledger trusts that item’s stock record less. When the record can’t be trusted, it hides the item from the app, sends a 30-second count and asks for a refill from the backroom.

Technical details
Relay · Agent 3 of 4

Rider-first packing

Decides which order goes to the pickers first, so the bag for the rider who arrives first is ready first. If a rider is late, it moves another order ahead.

Technical details
Promise · Agent 4 of 4

Missing items

Asks customers before they pay: if this item runs out, swap or refund? When an item is missing, it does exactly what the customer chose. It never guesses and never cancels the whole order.

Technical details
Optimiser · Plain code, not an agent

Fast optimiser

Batches orders, routes each trolley and assigns pickers every 5 seconds, in milliseconds. The agents change only its inputs and limits.

How the agents stay in sync

Coordination and guardrails

Agents never call each other. Events go through one bus, every agent writes only the shared-state fields it owns, and hard limits live in code, so no LLM proposal can override them.
